# Custom cspell dictionary for check:spelling-hr's Croatian prose sweep
# (the hand-translated `NoteSection` item/intro text inside
# `src/pages/hr/competitions/*.astro` and `src/pages/hr/competitions/ballon-dor.astro`/
# `golden-boot.astro`, on the built `/hr/*` pages).
#
# `@cspell/dict-hr-hr` (a general Croatian dictionary) has no notion of the
# proper nouns this site's editorial prose cites - player/manager/captain
# names, place and stadium names, Croatian declined forms of those names
# (Croatian is a case language: a surname like "Jašin" also appears as
# "Jašina"/"Jašinu" depending on grammatical case) - or of English award/
# competition-name fragments the site deliberately keeps untranslated
# (`Golden Boot`, `Fair Play`, `Final Four`, `FIFA`, ...), the same reason
# `.cspell/football-names.txt` exists for `content/*.md`'s English prose.
# Entries here are the exact inflected/declined forms found in the built
# site, not just nominative-case base forms - a generic dictionary or a
# stemmer can't derive "Beckenbaueru" (dative of "Beckenbauer") on its own.
#
# Add a new entry only after confirming it against the surrounding sentence
# (a real name/place/loanword, not a typo hiding behind an unfamiliar
# declined form) - this file is not the place to silence a real mistranslation,
# which is exactly the class of bug this check exists to catch (see the
# hundred-and-sixty-first intensive run's `presporno` -> `previše` fix).
